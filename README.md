# Market-Basket-Analysis-Using-Apriori
Retail-Market-Basket-Analysis
# Project Overview

This project performs Market Basket Analysis on retail transactional data to identify products frequently purchased together. Using the Apriori algorithm and association rule mining, the project uncovers customer buying patterns that support product bundling, cross-selling, inventory optimization, and personalized marketing strategies.

# Features
-Data Cleaning & Preprocessing
-Exploratory Data Analysis (EDA)
-Transaction Encoding
-Apriori Algorithm
-Association Rule Mining
-Support, Confidence & Lift Analysis
-Business Recommendations
